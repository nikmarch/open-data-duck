DuckDB-friendly public data index

Find authoritative open data sources and query them safely with DuckDB.

Open Data Duck does not mirror datasets. It stores source metadata, licenses, attribution, and executable query recipes so people and AI workers can plug in public datasets quickly, without Googling, configuring, or remembering every source.
