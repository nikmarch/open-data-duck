Plugin API direction

Attach once. Search the catalog table. Query the facade table.

The public site stays static for now. No fake terminal, no browser query runner, and no preset picker. The native extension resolves ODD table references with a replacement scan. Set the Overture S3 region before querying those facade tables. Registry validations keep each facade query paired with a direct DuckDB control.

INSTALL open_data_duck;
LOAD open_data_duck;

SET s3_region='us-west-2';

ATTACH ':memory:' AS odd (TYPE open_data_duck);

SELECT *
FROM odd.index
WHERE name ILIKE '%building%'
   OR source_type = 'overture';

SELECT table_reference, reader, path
FROM odd.tables
WHERE table_reference = 'odd.overturemaps.latest.building';

SELECT *
FROM odd.overturemaps.latest.building
WHERE bbox.xmin <= -149
  AND bbox.xmax >= -150
  AND bbox.ymin <= 61
  AND bbox.ymax >= 60
LIMIT 10;
