DuckDB-friendly public data index

Find authoritative open data sources and query them safely with DuckDB.

Open Data Duck does not mirror datasets. It stores source metadata, licenses, attribution, and executable query recipes so people and AI workers can plug in public datasets quickly, without Googling, configuring, or remembering every source.

Plugin API direction

Ask the index for a topic. Inspect the table. Then query it.

The public site stays static for now. No fake terminal, no browser query runner, and no preset picker.

INSTALL odd;
LOAD odd;

SELECT *
FROM odd_index('alaska building');

DESCRIBE odd.overturemaps.latest.buildings;

SELECT *
FROM odd.overturemaps.latest.buildings
LIMIT 10;
Example index response
match description table_reference
Overture buildings Building footprints from Overture Maps for Alaska and other regions. odd.overturemaps.latest.buildings
Anchorage building permits Local building permit records when an official open-data source is indexed. odd.local.anchorage.building_permits
