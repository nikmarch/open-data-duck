# Code of Conduct

Open Data Duck should stay useful, technical, and safe for contributors.

## Expected behavior

- Be direct and respectful.
- Argue from evidence: source terms, validation output, tests, and reproducible queries.
- Keep public discussions free of secrets, private data, and exploit details.
- Credit upstream data publishers and other contributors.
- Accept maintainer decisions on source inclusion, licensing risk, and security boundaries.

## Not acceptable

- Harassment, threats, or personal attacks.
- Publishing private data, secrets, credentials, or non-public datasets.
- Encouraging unauthorized scraping, access-control bypasses, or license evasion.
- Repeatedly submitting sources with invented attribution, unclear rights, or key-gated access after review feedback.

## Enforcement

Maintainers may edit, close, block, or remove issues, pull requests, comments, or registry entries that violate this code or create legal/security risk for the project.
